# NAT (Network Address Translation)

## NAT란

`NAT(Network Address Translation)`는 사설 네트워크의 호스트가 공인 IP를 통해 외부 네트워크와 통신할 수 있도록 IP 주소를 변환하는 기술이다.

## 사설 IP와 공인 IP

보통 사설 네트워크에 속한 호스트들은 공인 IP 주소를 통해 인터넷에 접속한다. 대부분의 경우 PC, 노트북, 스마트폰 등의 기기는 라우터가 제공하는 사설 IP를 사용한다.

IPv4 주소의 개수는 한정되어 있기 때문에, 동일한 사설 IP 대역을 여러 네트워크에서 재사용하고 NAT를 통해 하나의 공인 IP를 여러 기기가 함께 사용할 수 있도록 한다.

그렇다면 사설 IP를 할당받은 기기는 어떻게 인터넷을 사용할 수 있을까? `ifconfig`로 공공장소에서 공유기로부터 할당받은 IP를 살펴보면 다음과 같다.

```text
en0: flags=8863<UP,BROADCAST,SMART,RUNNING,SIMPLEX,MULTICAST> mtu 1500
	ether 82:9a:29:be:6d:03
	inet 192.168.219.62 netmask 0xffffff00 broadcast 192.168.219.255
```

### MAC 주소

같은 LAN 안에서 통신할 때 사용하는, 그 LAN 안에서만 유효한 주소다. 예를 들어 공유기는 `192.168.219.62`라는 IP를 가진 기기가 `82:9a:29:be:6d:03`이라는 MAC 주소를 가지고 있다는 것을 ARP를 통해 알 수 있다.

### IPv4 주소

`inet 192.168.219.62`처럼 표시되는, 현재 할당받은 사설 IP 주소다. 공유기의 `DHCP(Dynamic Host Configuration Protocol)`가 이 주소를 할당한다.

### 서브넷 마스크

`netmask 0xffffff00`은 `255.255.255.0(/24)`을 의미한다. 즉 현재 네트워크는 `192.168.219.0/24`이며, 사용 가능한 IP는 다음과 같다.

```text
192.168.219.1
~
192.168.219.254
```

> 사설 네트워크에서 사용 가능한 IP 주소 영역은 인터넷에서는 라우팅되지 않는 주소 대역이다.
>
> - 10.0.0.0 ~ 10.255.255.255
> - 172.16.0.0 ~ 172.31.255.255
> - 192.168.0.0 ~ 192.168.255.255

## NAT의 동작 원리

공유기에 연결된 모든 기기는 사설 IP를 할당받는다. 하지만 인터넷을 사용하려면 공인 IP를 통해야 한다.

즉 사설 IP(`192.168.219.62`)를 할당받은 기기는 인터넷을 사용하기 위해 공유기로 패킷을 전송하고, 공유기는 그 패킷의 출발지 IP를 자신의 공인 IP로 변환한 뒤 인터넷으로 전달한다. 이것이 `NAT(Network Address Translation)`의 원리이며, 이를 통해 사설 IP를 사용하는 기기도 인터넷의 다양한 서비스에 접근할 수 있다.

> 대부분의 가정용 공유기는 NAT와 함께 PAT(Port Address Translation)를 사용한다. 공인 IP 하나만으로도 여러 기기가 동시에 인터넷을 사용할 수 있는 이유는, IP뿐 아니라 포트 번호까지 함께 변환하기 때문이다.

## 정리

- `NAT`는 사설 IP를 공인 IP로 변환하여 외부 네트워크와 통신할 수 있도록 하는 기술이다.
- 공유기는 DHCP를 통해 내부 기기에 사설 IP를 할당하고, 인터넷으로 나가는 패킷의 출발지 IP를 자신의 공인 IP로 변환한다.
- 이를 통해 여러 기기가 하나의 공인 IP를 공유하며 인터넷을 사용할 수 있다.
- 대부분의 가정용 공유기는 NAT와 함께 PAT를 사용해 포트 번호까지 함께 변환하므로, 하나의 공인 IP로 여러 연결을 동시에 처리할 수 있다.
