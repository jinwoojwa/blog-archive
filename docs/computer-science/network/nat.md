## NAT (Network Address Translation)

**사설 네트워크의 호스트가 공인 IP를 통해 외부 네트워크와 통신할 수 있도록 IP 주소를 변환하는 기술**

보통 사설 네트워크에 속한 호스트들이 공인 IP 주소를 통해 인터넷에 접속하기 위해 사용됨 <br>
대부분의 경우 PC, 노트북, 스마트폰 등 기기들은 라우터가 제공하는 사설 IP를 사용 <br>
IPv4 주소의 개수가 한정되어 있기 때문에 동일한 사설 IP 대역을 여러 네트워크에서 재사용하고, <br>
NAT를 통해 하나의 공인 IP를 여러 기기가 함께 사용할 수 있음

**사설 IP를 할당받은 기기가 인터넷을 사용할 수 있게 하는 방법은?**

`ifconfig`로 공공장소에서 공유기로 할당 받은 IP를 살펴보면,

![할당받은 사설 IP 정보](/assets/images/ifconfig.png)

1. MAC 주소

- 같은 LAN 안에서 통신할 때 사용 (같은 LAN 안에서만 사용되는 주소)
- 예를 들어 공유기는 `192.168.219.62`라는 IP를 가진 기기가 `82:9a:29:be:6d:03`라는 MAC 주소를 가지고 있다는 것을 ARP를 통해 알 수 있음

2. IPv4 주소

- `inet 192.168.219.62`
- 현재 할당받은 사설 IP 주소
- 공유기의 `DHCP(Dynamic Host Configuration Protocol)`가 할당

3. 서브넷 마스크

- `netmask 0xffffff00` -> `255.255.255.0 (/24)`
- 즉, 현재 네트워크는 `192.168.219.0/24` 이며,
- 사용 가능한 IP는
  ```
  192.168.219.1
  ~
  192.168.219.254
  ```

> 사설 네트워크에서 사용 가능한 IP 주소 영역은 인터넷에서는 라우팅되지 않는 주소 대역 <br><br>
> 10.0.0.0 ~ 10.255.255.255 <br>
> 172.16.0.0 ~ 172.31.255.255 <br>
> 192.168.0.0 ~ 192.168.255.255

공유기에 연결된 모든 기기들은 사설 IP를 할당받음. <br>
하지만, 인터넷을 사용하려면 공인 IP를 통해야 함.

즉, 사설 IP(`192.168.219.62`)를 할당받은 기기는 인터넷을 사용하기 위해 공유기로 패킷을 전송하고, 공유기는 패킷의 출발지 IP를 자신의 공인 IP로 변환한 뒤 인터넷으로 전달함

이것이 `NAT (Network Address Translation)`의 원리

이를 통해 사설 IP를 사용하는 기기가 인터넷의 다양한 서비스에 접근할 수 있음

> 대부분의 가정용 공유기는 NAT와 함께 PAT(Port Address Translation)를 사용 <br>
> 공인 IP 하나만으로도 여러 기기가 동시에 인터넷을 사용할 수 있는 이유는 <br>
> IP뿐 아니라 포트 번호까지 함께 변환하기 때문

## 정리

- NAT(Network Address Translation)는 사설 IP를 공인 IP로 변환하여 외부 네트워크와 통신할 수 있도록 하는 기술
- 공유기는 DHCP를 통해 내부 기기에 사설 IP를 할당하고, 인터넷으로 나가는 패킷의 출발지 IP를 자신의 공인 IP로 변환함
- 이를 통해 여러 기기가 하나의 공인 IP를 공유하며 인터넷을 사용할 수 있음
- 대부분의 가정용 공유기는 NAT와 함께 PAT를 사용하여 포트 번호까지 함께 변환하므로 하나의 공인 IP로 여러 연결을 동시에 처리할 수 있음
